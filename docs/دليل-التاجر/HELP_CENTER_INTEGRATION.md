## 📥 تحميل دليل PDF

### الميزات:
✅ **دليل شامل** يشمل جميع الخطوات الـ 8  
✅ **رسومات وصور** لكل خطوة  
✅ **نصائح عملية** لتجنب الأخطاء الشائعة  
✅ **أسئلة شائعة** مع إجابات سريعة  
✅ **معلومات الدعم** والتواصل المباشر  

### كيفية التحميل:
1. اذهب إلى صفحة مركز المساعدة (`/help-center`)
2. اضغط على زر **"تحميل الدليل PDF"** في الأعلى
3. سيتم تحميل الدليل بصيغة `دليل-التاجر-الشامل.pdf`

---

## 🛠️ الملفات والمكونات المستخدمة

### 1. **HelpCenterPage.tsx**
- المكون الرئيسي لصفحة مركز المساعدة
- يحتوي على:
  - عرض الخطوات الـ 8 مع صور وشروحات
  - معلومات التواصل والدعم
  - أسئلة شائعة (FAQ)
  - زر تحميل PDF

**الموقع:** `src/pages/HelpCenterPage.tsx`

### 2. **generateMerchantPDF.ts**
- دالة عملية لتحويل محتوى الصفحة إلى PDF
- تستخدم:
  - `jsPDF` - لإنشاء ملفات PDF
  - `html2canvas` - لتحويل HTML إلى صور

**الموقع:** `src/utils/generateMerchantPDF.ts`

**الدوال المتاحة:**
```typescript
// تحويل العنصر إلى PDF object
generateMerchantPDF(elementId: string): Promise<jsPDF>

// تحميل الملف مباشرة
downloadMerchantPDF(filename: string): Promise<void>
```

### 3. **التكامل مع التوجيه (Routing)**
تم إضافة دعم كامل لمسارات مركز المساعدة:

```typescript
// في App.tsx
if (pathname === '/help-center' || pathname === '/help') {
  setCurrentPage('help-center');
}
```

### 4. **Lazy Loading**
تم تحسين الأداء باستخدام lazy loading:

```typescript
// في LazyPages.tsx
HelpCenter: React.lazy(() => import('@/pages/HelpCenterPage'))
```

## 📚 محتوى الدليل

يتضمن الدليل **8 خطوات شاملة**:

### الخطوة 1️⃣: معلومات التاجر الأساسية
- الاسم الكامل، البريد الإلكتروني، رقم الهاتف
- المدينة والدولة

### الخطوة 2️⃣: بيانات المتجر الأساسية
- اسم المتجر
- اسم النطاق (Subdomain) - ⚠️ لا يمكن تغييره
- الوصف والفئات

### الخطوة 3️⃣: بيانات التواصل والشبكات
- رقم الهاتف للعملاء
- البريد الإلكتروني
- حسابات التواصل الاجتماعية

### الخطوة 4️⃣: الوثائق والمستندات
- صورة الهوية
- الشهادات التجارية
- الصورة الشخصية

### الخطوة 5️⃣: شعار المتجر
- مواصفات الصورة
- الحد الأدنى والأفضل للحجم
- الصيغ المدعومة (PNG, JPG, WebP)

### الخطوة 6️⃣: إضافة المنتجات
- بيانات المنتج
- الأسعار والخصومات
- الصور والألوان

### الخطوة 7️⃣: سياسات المتجر
- سياسات الشحن
- سياسات الإرجاع
- شروط الضمان

### الخطوة 8️⃣: المراجعة والتفعيل
- التحقق من جميع البيانات
- تفعيل المتجر

## 🐛 استكشاف الأخطاء

### المشكلة: الصور لا تظهر في PDF
**الحل:**
```typescript
// استخدم رابط مطلق كامل
image: 'https://ishro.ly/images/step1.jpg'

// أو تأكد من أن الملف موجود في مجلد public
image: '/images/step1.jpg'
```

### المشكلة: PDF كبير جداً
**الحل:**
```typescript
// ضغط الصور قبل الاستخدام
// استخدم webp بدلاً من JPG
// قلل دقة html2canvas
scale: 1  // بدلاً من 2
```

### المشكلة: الخطوط العربية لا تظهر في PDF
**الحل:**
```typescript
// jsPDF يدعم العربية افتراضياً
// تأكد من استخدام نص عربي صحيح
```

## 🔐 الأمان والخصوصية

### بيانات التاجر:
- لا يتم حفظ أي بيانات شخصية في الدليل
- الدليل معلومات عامة فقط
- جميع البيانات تبقى في قاعدة البيانات الآمنة

### ملف PDF:
- لا يحتوي على أي بيانات حساسة
- يمكن للتاجر حفظه وطباعته بأمان
- لا يتم إرسالها إلى خوادم خارجية
