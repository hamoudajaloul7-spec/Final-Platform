1. اذهب إلى https://www.intercom.com
2. اضغط "Get started"
3. أنشئ حساباً بـ:
   - البريد الإلكتروني الخاص بك
   - كلمة مرور قوية

1. من لوحة التحكم Intercom → Settings

   - **App ID**: يبدأ بـ `xxx`

## 💻 التنفيذ الفني

### **ملف التكوين (.env)**

أضف إلى `.env`:
```env
VITE_INTERCOM_APP_ID=your_app_id_here
VITE_INTERCOM_API_KEY=your_api_key_here
```

### **مكون React لـ Intercom**

أنشئ `src/components/IntercomWidget.tsx`:

```typescript
import { useEffect } from 'react';
import { useAuth } from '@/context/AuthContext'; // تعديل حسب auth provider

export function IntercomWidget() {
  const { user } = useAuth();

  useEffect(() => {
    if (typeof window === 'undefined') return;

    // تحميل سكريبت Intercom
    const script = document.createElement('script');
    script.async = true;
    script.src = 'https://widget.intercom.io/widget/' + import.meta.env.VITE_INTERCOM_APP_ID;
    document.head.appendChild(script);

    return () => {
      if (script.parentNode) {
        script.parentNode.removeChild(script);
      }
    };
  }, []);

  // تحديث بيانات المستخدم
  useEffect(() => {
    if (window.Intercom && user) {
      window.Intercom('boot', {
        app_id: import.meta.env.VITE_INTERCOM_APP_ID,
        name: user.name,
        email: user.email,
        user_id: user.id,
        created_at: Math.floor(new Date(user.createdAt).getTime() / 1000),
        role: user.role || 'merchant', // تاجر أو عميل
        custom_attributes: {
          store_id: user.storeId,
          store_name: user.storeName,
          account_type: user.accountType,
        },
      });
    }
  }, [user]);

  return null; // الـ widget يظهر تلقائياً
}
```

### **دمج المكون في App.tsx**

```typescript
import { IntercomWidget } from '@/components/IntercomWidget';

export default function App() {
  return (
    <>
      <Router>
        {/* باقي الكود */}
      </Router>
      <IntercomWidget />
    </>
  );
}
```

### **ملف TypeScript للـ Window Interface**

أضف إلى `src/types/intercom.d.ts`:

```typescript
declare global {
  interface Window {
    Intercom?: (
      command: string,
      data?: Record<string, any>
    ) => void;
  }
}

export {};
```

## 🎯 رسائل الترحيب التلقائية

### **إنشاء رسالة ترحيب للتاجر الجديد**

من Intercom Dashboard:

1. **Messenger** → **Campaigns**
2. **+ New** → **Automated Message**
3. **اسم الحملة**: "رسالة ترحيب التاجر"
4. **الشرط**: User tag = "new_merchant"
5. **الرسالة**:
```
مرحباً {{name}}! 👋

شكراً لاختيارك إشرو كمنصة لبيع منتجاتك!

نحن هنا لمساعدتك:
✅ إعداد متجرك
✅ إضافة المنتجات
✅ الإجابة على استفساراتك

هل تحتاج مساعدة في البدء؟

نصيحة: اطلع على دليل التاجر الكامل:
👉 [رابط الدليل]
```

### **رسالة لتذكير بإتمام الإنشاء**

**الشرط**: 2 ساعات بعد البدء
**الرسالة**:
```
حي {{name}}، كيف يسير إنشاء متجرك؟ 😊

إذا واجهت أي مشكلة، أنا هنا لمساعدتك:
📞 اضغط هنا للدعم الحي
📧 أو ارسل لنا بريد: support@ishro.ly
```

## 👥 إدارة فريق الدعم

### **إضافة أعضاء الفريق:**

1. **Settings** → **Team Members**
2. **+ Invite** → أضف البريد الإلكتروني
3. **Role**: اختر الدور:
   - **Admin**: تحكم كامل
   - **Operator**: رد على الرسائل فقط
   - **Analyst**: عرض التقارير فقط

### **توزيع الحالات:**

```
- المحادثات الجديدة → قائمة الانتظار
- تاجر جديد → Operator 1
- مشكلة تقنية → Operator 2 (فني)
- شكوى → Admin
- استفسار عام → أي Operator متاح
```
