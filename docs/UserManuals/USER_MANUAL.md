# 📖 دليل المستخدم - User Manual

**الإصدار:** 2.0 (Production)
**الفئة المستهدفة:** الزوار، المتسوقين، التجار

---

## 1. للزوار والمتسوقين (Shoppers)

### 🛍️ كيفية التصفح والشراء
1.  **الصفحة الرئيسية:** ستجد "سلايدر" يعرض كافة المتاجر المتاحة (مثل Delta Store, Magna Beauty).
2.  **دخول المتجر:** انقر على "تسوق الآن" للدخول لمتجر معين.
3.  **إضافة للمفضلة:** انقر على أيقونة ❤️ لحفظ المنتج (يتطلب تسجيل دخول).
4.  **إتمام الشراء:**
    *   أضف المنتجات للسلة.
    *   انقر على أيقونة السلة وأكمل عملية الدفع.
    *   يمكنك اختيار "الدفع عند الاستلام" أو الدفع الإلكتروني.

### 📦 تتبع الطلبات
*   بعد إتمام الطلب، ستصلك رسالة بريد إلكتروني تحتوي على تفاصيل الطلب.
*   يمكنك متابعة حالة الطلب من صفحة "طلباتي" في لوحة التحكم الشخصية.

---

## 2. للتجار (Merchants)

### 🏪 كيفية إنشاء متجر جديد
1.  انتقل إلى صفحة "إنشاء متجر" من القائمة الرئيسية.
2.  أدخل اسم المتجر، الوصف، والشعار.
3.  سيقوم النظام تلقائياً بإنشاء صفحة خاصة لمتجرك (مثلاً: `/store/my-new-store`).

### 📊 إدارة المتجر (Merchant Dashboard)
*   **إضافة منتجات:** يمكنك إضافة صور، وصف، وسعر، وتحديد الكمية المتاحة.
*   **إدارة الطلبات:** ستظهر الطلبات الجديدة فوراً. يمكنك تغيير حالتها إلى "جاري التجهيز" أو "تم الشحن".
*   **التحليلات:** متابعة المبيعات اليومية والأسبوعية.
