# شرح المشكلة والحل - بالعربية

## 🔍 المشكلة المكتشفة

### الخطأ الذي ظهر:
```
ERROR: column "password_hash" does not exist
```

### ماذا يعني هذا؟

جدول `users` في قاعدة البيانات **لا يحتوي على عمود `password_hash`**!

---

## 📊 كيف يتم المصادقة (تسجيل الدخول)؟

### نظام تسجيل الدخول يعمل كالتالي:

```
┌─────────────────────────────────────────────────────────┐
│                   نظام المصادقة في منصة إشرو              │
├─────────────────────────────────────────────────────────┤
│                                                         │
│   1. المستخدم يدخل البريد وكلمة المرور                   │
│              ↓                                          │

│              ↓                                          │

│                                                         │
└─────────────────────────────────────────────────────────┘
```

## 🔍 كيف نتحقق؟

### الطريقة 1: من لوحة التحكم Supabase

1. اذهب إلى: https://database.supabase.com/project/wbakbuqvdbmweujkbzxn/auth/users
2. ابحث عن المستخدم: `salem.mfurjani@gmail.com`
3. هل تجده؟

### الطريقة 2: بتشغيل استعلام SQL

```sql
-- تحقق من Supabase Auth (جدول مختلف)
SELECT email, encrypted_password, confirmed_at
FROM auth.users
WHERE email = 'salem.mfurjani@gmail.com';
```

## ❌ إذا المستخدم غير موجود في Auth:

### الحل 1: دعوة المستخدم (موصى به)

1. اذهب إلى: https://database.supabase.com/project/wbakbuqvdbmweujkbzxn/auth/users
2. اضغط على: **Invite User**
3. أدخل: `salem.mfurjani@gmail.com`
4. المستخدم سيستقبل إيميل الدعوة
5. يفتح الرابط ويعين كلمة مرور جديدة

### الحل 2: حذف وإعادة إنشاء

إذا الحل 1 ما نجح:

```sql
-- حذف من جدول المستخدمين
DELETE FROM users WHERE email = 'salem.mfurjani@gmail.com';

-- حذف المتجر
DELETE FROM stores WHERE slug = 'shekha';

-- حذف من جدول التجار
DELETE FROM merchants WHERE store_slug = 'shekha';
```

ثم أنشئ المتجر مرة أخرى من خلال الخطوات 8

## 🎉 الخلاصة:

**المشكلة:** المستخدم تم حفظه في جدول `users` لكن **لم يتم إنشاؤه في نظام Supabase Auth** بشكل صحيح.

1. دعوة المستخدم (Invite)
2. أو حذف وإعادة إنشاء
