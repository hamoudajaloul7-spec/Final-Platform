# 🛡️ مستوى الأمان والحماية - Security Level Document

**تاريخ التحديث:** 28 ديسمبر 2025
**الحالة:** مُؤمّن (Hardened)

---

## 1. ملخص الحالة الأمنية (Security Overview)
تم تصميم منصة "إشروا" باتباع مبدأ **"الأمان حسب التصميم" (Security by Design)**. تم تعزيز النظام مؤخراً لمنع تسرب البيانات وحماية الجلسات.

---

## 2. طبقات الحماية المطبقة (Implemented Security Layers)

### 🔐 حماية الخصوصية والبيانات (Privacy & Data Protection)
*   **تعطيل الإكمال التلقائي (Autocomplete Disabled):**
    *   تم تعديل كافة حقول الإدخال الحساسة (البريد، الهاتف، كلمات المرور) لتشمل الخاصية `autoComplete="off"`.
    *   **الهدف:** منع المتصفحات من تخزين أو اقتراح بيانات مستخدمين سابقين، خاصة عند استخدام أجهزة مشتركة (مثل نقاط البيع أو أجهزة الموظفين).
    *   **المناطق المغطاة:** تسجيل دخول المتجر، إنشاء متجر جديد، تسجيل الزوار.

### 🔑 المصادقة والتحقق (Authentication & Authorization)
*   **JWT (JSON Web Tokens):** استخدام رموز مشفرة وموقعة رقمياً لإدارة الجلسات دون تخزين الحالة على الخادم.
*   **Password Hashing:** يتم تشفير كلمات المرور باستخدام `bcrypt` قبل تخزينها في قاعدة البيانات.
*   **Role-Based Access (RBAC):** فصل الصلاحيات بين (Admin, Merchant, Visitor).

### 🌐 حماية الشبكة والاتصال (Network Security)
*   **HTTPS Enforcement:** جميع الاتصالات مشفرة باستخدام SSL/TLS (مفعل تلقائياً عبر Vercel/Render).
*   **CORS Policy:** تقييد طلبات API لتأتي فقط من النطاق المعتمد (Frontend Domain).

---

## 3. التعامل مع البيانات الحساسة
*   لا يتم تخزين بيانات بطاقات الائتمان على خوادمنا نهائياً (يتم استخدام بوابات دفع خارجية مؤمنة).
*   يتم تنقية المدخلات (Input Sanitization) لمنع هجمات XSS و SQL Injection (عبر Mongoose).
